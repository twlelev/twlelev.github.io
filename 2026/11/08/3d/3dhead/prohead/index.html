ProHead：从单张照片到三维头部资产

我的相关工作围绕一个目标展开：从单张人像照片生成具有统一网格结构和完整颜色贴图的三维头部，并将重建、纹理优化、数据建设和结果验证连接成完整流程。

目前已形成从照片输入到头部模型、UV 贴图和组合渲染的阶段成果。本文结合项目论文 v1 与更新后的模型结果，集中介绍整体方案、已完成的工作和当前效果。

Overview：整体流程

查看流程图原图

整体框架采用当前 Draft.md 中的 overview。一张 RGB 照片经过统一对齐后，分别进入头部表面重建和区域毛发预测两条支路，最后组合为带纹理网格与毛发的头部资产。

阶段 完成的工作 形成的结果
头部几何重建 结合稠密图像信息与图像特征，直接预测网格顶点 统一拓扑的头部模型
纹理补全 结合 UV 特征与可见 BaseColor，预测完整颜色贴图 与头部表面对齐的 RGB UV 图集
区域毛发重建 预测头发、胡须和眉毛的区域发丝，并在变形后的区域表面放置发根 各区域的发丝曲线及头发颜色
资产组装 组合带纹理网格与区域毛发 网格与毛发共同构成的头部资产

几何侧负责头部形状和图像对应，纹理侧负责全头颜色与局部细节。 两者通过明确的对应关系连接，照片中的鼻部、面颊和唇部信息才能放到相应的三维表面。

这里的 UV 贴图可以理解为头部表面的展开图，BaseColor 是用于表面着色的基础颜色。各阶段输出可以分别检查，再将同一网格和贴图组合渲染，观察最终表面效果。

这张图展示当前论文草稿的整体框架。本文下文侧重头部网格与 UV 纹理的阶段成果，其中包含历史 PCA 基础贴图与细化方案；这些结果与整体框架图分别说明，不代表已验证全部毛发组装能力。六样本结果和多视角图没有附加外部纹理恢复。

阶段成果：输入照片到头部资产

每行依次展示输入照片、正面重建、几何、网格结构、完整 UV 贴图、三组指定灯光，以及张嘴、微笑和压眉演示。不同人物沿用相同的网格连接关系和 UV 布局，便于使用一致的方式组织模型、管理贴图和检查结果。

这组成果已将照片、头部几何和外观组织为可渲染的组合，并进行了后续绑定接入探索。表情演示借助适配的外部 Ada 绑定，灯光由展示程序指定；图中未包含头发、胡须和眉毛的独立毛发资产。

几何重建：恢复人物形状，建立表面对应

几何侧的工作从照片信息预测开始，建立模板顶点与输入图像之间的对应，再结合局部观察和整体头部信息恢复人物形状。输出包括头部网格、修正后的图像对应和相对深度，供后续贴图对齐与遮挡处理使用。

左列为初始搜索到的照片位置，中列为网络修正后的对应，右列为预测的三维头部。两组对应点使用相同顶点子集和颜色，便于观察位置变化；纯几何视图则用于检查脸型、五官和表面结构。

这一部分同时关注图像信息是否取对位置，以及最后生成的三维形状是否合理。统一网格结构还让不同人物的输出保留一致的顶点顺序和表面组织，为贴图管理、模型编辑和后续绑定提供基础。

纹理生成：先完整，再补充局部细节

完整基础贴图

照片只提供一个视角，可见皮肤以外的区域缺少直接观察。因此，纹理侧首先生成覆盖完整头部的基础贴图，建立整体肤色和区域之间的颜色衔接，再进一步恢复细节。

这组样例使用相同照片、网格和共享底图。橙色列为不经过 PCA 纹理空间约束的直接增强，绿色列为经过该约束的贴图及对应渲染。对照中可以看到，直接增强容易出现明显的人脸覆盖边界，完整纹理约束后的全头颜色更加连续。

这部分工作主要解决完整性与整体颜色。耳侧、头顶和背侧等不可见区域依然包含模型补全，人物特有的真实外观需要额外观测才能确认。

局部纹理细化

从左到右为输入照片、重建几何、基础外观和细化外观。细化阶段在完整底图上增加鼻唇区域、面颊等位置的局部颜色变化，下方对相同区域进行放大。

当前采用基础纹理与细化网络分工的方式，分别处理全局完整性和局部变化。已有结果能够呈现阶段间的差异，但浓密胡须等人物特征仍有丢失，细节保持还需要继续改善。

结果检查：从贴图平面到三维表面

六个固定样本的重建结果

下面使用六个固定样本，展示同一组模型资源从基础贴图、可见颜色条件到最终 UV 和头部渲染的完整输出，便于逐步检查人物特征、肤色和五官边界。

每行依次为原始照片、PCA 基础 UV、可见 UV BaseColor 条件、细化后的最终 UV，以及放回原图构图的头部渲染。样本为 FFHQ 02183、05539、15196、28548、45299 和 60494。

这些图使用模型直接输出，没有额外的 restored 纹理。头部渲染覆盖范围之外保留了原始照片的背景与头发，它们属于上下文，不是生成结果。查看 FFHQ 02183 高清结果，其中同时展示最终贴图、可见 UV 条件、支持范围和独立头部渲染。

多角度检查

每行依次展示原始照片、最终 UV 和六个旋转视角。固定同一个预测网格和同一张最终贴图，在正面拟合的仿射投影下旋转到 −75°、−45°、−15°、+15°、+45°、+75°，检查耳侧、面颊边缘和轮廓附近的连续性。

这些视角由生成的模型旋转得到，输入仍是一张照片。检查重点是已有资产在不同角度下的外观衔接，未观测区域的真实性还需要独立验证。

相同输入的纹理对照

新版对比图从左到右为原始照片、FaceRefiner、MARCUS-Avatar、refactor/pipeline-v2 和 prohead-pipeline。后两列分别展示 Direct RGB 与 PCA 基础贴图加细化两条分支，使用相同的八张输入照片。

各列保留对应方法和分支的实际输出。不同分支使用各自的模型资源，不同方法的 UV 布局也存在差异，因此这张图用于观察肤色、局部细节和完整性，不能作为单独替换纹理模块的受控消融或逐像素误差排名。

数据建设：结合头部资产与真实照片

路线 已记录的建设内容 作用
头部资产扩展 从 1,500 组 MetaHuman 头部与配对贴图出发，组合形状和外观，再通过 Unreal Engine 渲染 提供带有几何和颜色标注的训练样本
真实照片扩展 从 FFHQ、CelebA 等正面人像生成 UV，质量筛选后保留约 35,000 张贴图，再分配到头部资产渲染 扩展真实人脸的外观变化

两条路线使用统一的网格和 UV 布局，连接数据构建与重建训练。约 35,000 指保留的照片来源贴图数量，同一贴图可以用于多张渲染图；其中不可见区域包含推测内容。这里沿用论文 v1 的数据记录。

阶段验证：已有结果说明了什么

对应修正

论文 v1 在 64 条合成验证记录上，将初始搜索位置和网络输出位置与相同参考坐标比较。

指标 初始对应 网络输出
平均对应误差，越低越好 9.93 px 2.35 px
误差在 5 px 内的对应比例，越高越好 36.32% 93.07%
误差在 10 px 内的对应比例，越高越好 64.36% 99.58%

平均误差按未取整数据计算下降 76.28%，64 条记录的平均误差均降低。这说明在该组固定样本上，重建网络能够修正自身初始对应中的偏差。误差使用 1024×1024 对齐图像坐标，数据按记录划分，尚未建立人物独立性。

这些验证分别服务于对应修正、图像预测和几何方案筛选。它们具有各自的实验背景，跨人物泛化、复杂输入和最终资产质量仍需更完整的测试。

当前进展与后续方向

目前已形成照片到固定拓扑头部、完整 UV BaseColor 和组合渲染的阶段流程，并沉淀了纹理质量排查、数据构建和内部验证记录。基于这些输出，还完成了多角度检查、指定灯光展示和外部绑定下的轻度表情演示。

后续工作主要集中在四个方面：

  • 人物特征与纹理细节：改善胡须、皱纹等局部特征的保持，减少颜色漂移与 UV 边界问题。
  • 复杂输入稳定性：分别检查侧脸、遮挡和异常光照下的重建表现。
  • 几何与相机一致性：加强图像视角对齐、导出网格和三维投影之间的一致性。
  • 独立人物与资产验证：补充未见人物测试，以及绑定变形和后续编辑流程中的检查。

本篇展示以头部网格和颜色贴图为核心。多视角与表情图反映当前的检查和接入探索，完整生产可用性仍需进一步验证。
