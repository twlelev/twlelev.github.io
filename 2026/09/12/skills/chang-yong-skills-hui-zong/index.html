这是一份个人常用 Skills 导航，按“我要完成什么”来分类。Skill 可以理解为给 AI agent 的专业工作手册：既可以直接点名，也可以用自然语言描述任务，让 Codex 自动选择合适的 Skill。

显式调用示例：$pdf 把这份报告整理成 PDF

自然语言示例：把这组数据做成带图表的 Excel，并检查公式。

高频入口

Skill 适合做什么 一句话用法
imagegen 生成或编辑图片、插画、封面和视觉素材 “生成一张适合博客头图的 AI 工具插画”
visualize 把关系、流程和数据做成交互式图表或小工具 “把这个系统架构可视化”
documents 创建、编辑和检查 Word 文档 “把这些笔记整理成排版完整的 Word”
pdf 阅读、生成、填写和校验 PDF “总结这份 PDF，并输出中文版报告”
presentations 创建或修改 PowerPoint / Google Slides “把这份方案做成 10 页演示文稿”
spreadsheets 处理 Excel、CSV、公式、格式和图表 “分析 CSV，输出带透视表和图表的 Excel”
research-lit 查找相关论文、梳理研究脉络和核心观点 “找近三年相关论文并做文献综述”
openai-docs 查询 Codex、ChatGPT 和 OpenAI API 的官方用法 “确认 Responses API 的最新调用方式”

研究与知识整理

Skill 简介
paper-search 按关键词、DOI 或 OpenAlex ID 定位学术论文，适合快速找文献。
research-lit 搜索并分析论文、寻找相关工作、比较方法，适合普通文献调研。
deep-research 面向明确的深度研究任务，产出覆盖更全面、带引用的研究报告。
openai-docs 以官方资料为准回答 OpenAI 产品、API、模型、定价与 Codex 配置问题。

文档与数据交付

Skill 简介
documents 创建、编辑、批注和校验 .docx，并通过渲染检查最终版式。
pdf 提取、创建、渲染和检查 PDF，也适合处理可填写表单。
presentations 创建或修改 .pptx / Google Slides，兼顾内容结构和视觉呈现。
spreadsheets 创建、分析和可视化 .xlsx、.csv、.tsv，支持公式、表格和图表。
excel-live-control 控制已经打开并连接的 Excel 工作簿，适合边看边改。
template-creator 把现有文档、表格或演示稿整理成可反复使用的个人模板 Skill。

图片、可视化与网站

Skill 简介
imagegen 生成新的位图素材，或按要求编辑已有图片。
visualize 创建图表、流程、地图、交互演示和小型模拟工具。
sites-building 从零构建完整网站，如作品集、看板、门户和内部工具。
sites-hosting 发布由 Sites 构建的网站，并管理后续部署。
sites-preview-troubleshooting 诊断和恢复 Sites 预览失败的问题。

扩展与维护 Agent 能力

Skill 简介
skill-creator 创建或更新一个边界清晰、可复用的 Codex Skill。
skill-installer 从精选列表或 GitHub 仓库安装 Codex Skills。
plugin-creator 创建 Codex 插件目录、清单和可选能力结构。
plugin-management 发现、检查、连接或移除插件与外部服务。

代码库与知识图谱工具

当前分类中另有一篇专文，详细对比以下两个工具：

  • codebase-memory-mcp：把代码解析为持久化知识图谱，适合大型仓库的架构、调用链和改动影响分析。
  • graphify：把代码、文档、论文和图片整理成知识图谱与 wiki，适合跨资料发现关联。

怎么选

  • 要交付文件：按格式选择 documents、pdf、presentations 或 spreadsheets。
  • 要理解研究：先用 paper-search 找文献，再用 research-lit 分析；需要完整专题报告时用 deep-research。
  • 要做视觉内容：静态图片用 imagegen，关系与交互展示用 visualize。
  • 要搭建并发布网页：组合使用 sites-building 与 sites-hosting。
  • 要新增能力：先判断是单一工作流还是外部服务集成，再选 skill-creator 或 plugin-creator。
