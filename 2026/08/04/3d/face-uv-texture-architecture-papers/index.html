1. Yin et al. (2021)：UV sampler 负责“抄对”，generator 负责“补全”

论文：Weakly-Supervised Photo-realistic Texture Generation for 3D Face Reconstruction

图 1：论文 Figure 3。左侧构造弱监督 UV，中央是 UV sampler 与 UV generator，右侧通过可微渲染和三个判别器约束整体人脸、侧脸 UV 与中央五官 UV。

简介：这篇工作把单图人脸纹理生成明确拆成两个问题。UV sampler 学习从输入图像坐标到 canonical UV 坐标的采样关系，尽量只搬运真实可见像素；UV generator 再对残缺 UV 做补全。这样避免让一个网络同时学习精确对应关系和大面积内容生成。

具体数据流：

  1. 输入图像 III 经现成的 shape regressor 获得粗 3D 形状和相机；传统投影得到不完整的监督纹理 UVgtUV_{gt}UVgt​。
  2. BFM 平均纹理 UVbfmUV_{bfm}UVbfm​ 与 UVgtUV_{gt}UVgt​ 经 Poisson blending 得到伪完整监督 UVblUV_{bl}UVbl​。
  3. UV sampler 输出采样场，将 III 变为 UVsampleUV_{sample}UVsample​；以 UVgtUV_{gt}UVgt​ 和渲染回输入视角的重建误差监督采样准确性。
  4. UV generator 把 UVsampleUV_{sample}UVsample​ 补成 UVpredUV_{pred}UVpred​，以 UVblUV_{bl}UVbl​ 提供像素监督。
  5. UVpredUV_{pred}UVpred​ 被旋转并渲染成正面/侧面图送入 DfaceD_{face}Dface​；侧脸和中央五官裁块分别送入 DsdD_{sd}Dsd​、DctrD_{ctr}Dctr​，避免局部模糊和结构漂移。

实现本质：这是 CNN sampling field + image-to-image generator + differentiable rendering + multi-part GAN，不是 diffusion；最终输出仍是包含拍摄光照的 RGB texture。

2. FFHQ-UV (2023)：先规范化多视图，再生产大规模 UV 数据

论文：FFHQ-UV: Normalized Facial UV-Texture Dataset for 3D Face Reconstruction

图 2：论文 Figure 2。该图是 UV 数据生产框架，而非端到端 diffusion 网络。

简介：FFHQ-UV 的核心贡献不是“输入一张图直接生成 UV 的新网络”，而是一个自动化数据引擎：先把野外图像变成光照、姿态、表情更受控的多视图，再将它们融合成高质量 canonical UV。生成的 54,165 张 1024×1024 UV 随后用于训练非线性 GAN texture decoder。

具体数据流：

  1. 将输入人脸反演到 StyleGAN latent space，编辑出正面、左侧、右侧的 normalized multi-view faces，同时弱化原始姿态、表情、眼镜、头发和照明干扰。
  2. 对三个视角分别进行 3D face fitting 和 UV unwrapping，得到 Tl,Tf,TrT_l,T_f,T_rTl​,Tf​,Tr​。
  3. 使用预定义 visibility masks 线性融合三个 UV，最大化真实可见纹理覆盖率。
  4. 依据 face parsing 与亮度规则检测眼球、口腔、鼻孔等错位 artifact；用 Poisson editing 修补局部区域。
  5. 对脸外、耳朵和脖颈等缺失区域使用 template UV，并通过颜色匹配与 Laplacian pyramid blending 得到最终 T^final\hat T_{final}T^final​。

实现本质：它用 StyleGAN 编辑 + 传统 3D unwrap + mask blending + 图像融合 换取规模化 UV 数据。后续 texture decoder 才是学习式纹理基底；因此比较网络架构时，应把它视为数据/先验路线，而不是与 UV-IDM 完全同类的生成器。

3. UV-IDM (CVPR 2024)：将 identity condition 注入 UV latent diffusion

论文：UV-IDM: Identity-Conditioned Latent Diffusion Model for Face UV-Texture Generation

图 3：论文 Figure 4。上方为 Identity-Conditioned Module，左下为 UV-VAE，右下为 latent diffusion denoiser。雪花表示冻结，火焰表示训练。

简介：UV-IDM 将完整人脸 UV 看作一个条件生成问题：LDM 负责学习 BFM-UV 的完整纹理分布，Identity-Conditioned Module（ICM）把输入中可靠、可见且属于皮肤的 texel 变成条件，约束扩散过程不要把人物“换脸”。

具体数据流：

  1. ICM 中，冻结的 Deep3D 估计 3D 顶点与相机，冻结的 BiSeNet 预测人脸分割；二者 remap 到 UV 后形成 visibility mask MvisM_{vis}Mvis​ 与 semantic mask MsegM_{seg}Mseg​。
  2. 两个 mask 与输入反投影纹理逐点相乘，得到去除头发、眼镜和不可见区的 incomplete UV condition yyy；嵌入网络 τθ\tau_\thetaτθ​ 将其编码为条件 token。
  3. 独立训练 UV-VAE：编码器 E\mathcal EE 把 256×256 UV 压缩为 32×32×432\times32\times432×32×4 latent，解码器 D\mathcal DD 重建 UV；损失由 KL、GAN 与 LPIPS 组成。
  4. 在 latent space 中训练 LDM denoiser ϵθ\epsilon_\thetaϵθ​；τθ(y)\tau_\theta(y)τθ​(y) 通过多层 cross-attention 注入 U-Net，在每个去噪时间步提供身份约束。
  5. 训练顺序是先训练 VAE，再冻结 VAE，联合训练 ICM 与 LDM；推理后将去噪 latent 经 D\mathcal DD 解码为完整 BFM UV。

实现本质：相较一般 Stable Diffusion，关键改动是 UV 专用 VAE + 几何/分割构造的 partial-UV condition + 多尺度 cross-attention。

4. FreeUV (CVPR 2025)：分别学习真实外观与 UV 结构，推理时组装

论文：FreeUV: Ground-Truth-Free Realistic Facial UV Texture Recovery via Cross-Assembly Inference

图 4：论文 Figure 3。左侧 appearance network 在野外数据上学习真实细节，中间 structure network 在 3DMM 域学习 UV 结构，右侧在不重新训练的情况下 Cross-Assembly。

简介：真实照片有细节却没有完整 UV 真值；3DMM UV 结构正确却过于平滑。FreeUV 不要求一个训练集同时具备两者，而是把这两个知识源拆开训练，再在推理阶段交叉组装。

具体数据流：

  1. Appearance network ϕa\phi_aϕa​：在 in-the-wild 数据上训练。Flaw-Tolerant Facial Detail Extractor ψa\psi_aψa​ 用冻结 CLIP image encoder 提取展开 UV 中的身份细节，并用 channel attention 降低破损/错位 texel 的影响；ControlNets 接收 2D UV mask 与 landmark 条件。
  2. Structure network ϕs\phi_sϕs​：在可合成完整真值的 3DMM 域训练。UV Structure Aligner ψs\psi_sψs​ 以 self-attention 建模 canonical UV 的长距离结构，ControlNet 注入 completed UV coordinate map。
  3. Cross-Assembly inference：保留 appearance branch 的生成 U-Net 和 ψa\psi_aψa​，接入 structure branch 的 UV aligner/ControlNet，使同一次去噪同时获得真实皮肤外观和稳定 UV 布局。
  4. 最后进行 Lab color adjustment，缓解 classifier-free guidance 放大细节时产生的整体色偏。

实现本质：它是 两个异域 diffusion/ControlNet 专家在推理期组合。优势是不需要 paired image–UV GT；风险是两个专家在大面积不可见区仍可能对身份作出不一致猜测。

5. OMGTex (CVPR 2026)：绕开 3D fitting，直接学习 image-to-UV

论文：OMGTex: One-stage Multi-style Facial Texture Reconstruction without Geometry Guidance

图 5：论文 Figure 3。左侧生成 CANVAS paired data，右侧用冻结 FLUX.1 和可训练条件 LoRA 学习从人脸图像到 texture latent 的映射。

简介：传统方法先拟合 3DMM 再反投影 texel，一旦输入存在手部、眼镜、面具、强风格化或极端姿态，几何拟合可能先失败。OMGTex 直接把单张图像映射为 canonical UV，把几何依赖转移为数据学习和推理时对齐约束。

具体数据流：

  1. CANVAS 构建：AvatarTex 先产生基础 facial texture；FLUX augmentation 将对应输入扩展为姿态、遮挡和多风格版本；人工 correction 修复 UV 标签中的系统性错误，形成 image–UV pair。
  2. 输入图像经 VAE encoder 得到 conditional embedding；目标 UV 被另一个 VAE 编码为 latent，并加噪作为 FLUX.1 的生成变量。
  3. 冻结 FLUX.1 的 double-stream/single-stream 主干，只在各 block 的 self-attention QKV projection 上训练 LoRA，将 condition token 注入 noise-token 更新过程。
  4. 以 rectified-flow/flow-matching 形式的 LRFL_{RF}LRF​ 监督 predicted latent 接近 ground-truth texture latent。
  5. 推理得到 raw UV 后，以 Gradient-Guided Texture Alignment 对眼、口、眉等语义区域做梯度纠偏；编辑版本还可对指定区域注入参考特征。

实现本质：这是 FLUX.1 backbone + parameter-efficient condition LoRA + inference-time gradient correction。它去掉显式 geometry guidance，但 canonical 对齐并未消失，而是由 paired data 与后验梯度共同承担。

6. FaceRefiner (2026)：把可微渲染变成 UV 精修的反馈回路

论文：FaceRefiner: Training-Free Generation Refinement for High-Fidelity 3D Facial Texture Reconstruction

图 6：论文 Figure 2。灰框准备输入，蓝框在 UV 空间执行 style/content optimization，橙框把当前 UV 渲染回输入相机并提供 rendering loss。

简介：FaceRefiner 不是新的 UV generator，而是一个 training-free 后处理器。完整生成 UV 提供全局 content；从原图反投影得到的残缺 UV 虽有黑洞，却包含最可靠的身份 style。优化目标是在不破坏完整性的前提下，把真实可见细节迁回生成 UV。

具体数据流：

  1. 输入图 III 经任意 3D face reconstruction 得到 mesh M\mathcal MM、camera pose P\mathcal PP 和 sampled partial texture ISI_SIS​；已有生成方法给出完整但不够像输入的 ICI_CIC​。
  2. 待优化纹理 IXI_XIX​ 同时接受 content loss（保持 ICI_CIC​ 的完整布局）和 ROI style loss（从 ISI_SIS​ 的有效区域恢复肤色、斑点、眼周等身份特征）。
  3. 可微渲染器用 (IX,M,P)(I_X,\mathcal M,\mathcal P)(IX​,M,P) 生成输入视角 IRI_RIR​；rendering loss 直接度量 IRI_RIR​ 与原图 III 的像素/感知差异。
  4. 渲染梯度反传到 UV texel；五阶段优化逐步降低对初始 content 的依赖并加强输入视角约束，减轻一次优化出现的 content leakage。

实现本质：这是 neural style transfer optimizer + differentiable renderer；没有额外训练数据，但每个样本都要迭代优化，且结果上限受初始 UV 和 mesh/camera 精度限制。

7. HiFiAlbedo (2024)：先学高频纹理字典，再适配到 albedo 域

论文：HiFiAlbedo: High-Fidelity Face Albedo Estimation via Texture Codebook

图 7a：论文 Figure 3。VQ texture codebook 和 decoder 冻结，只微调 image-to-UV encoder；latent/image 双判别器同时约束隐空间分布和多视图渲染真实性。

图 7b：论文 Figure 4。同身份多图经共享 encoder 后，由 learnable query 与 key/value latent 做 cross-attention，提取跨场景稳定的 albedo latent。

简介：直接在小规模 Light-Stage albedo 上训练容易过拟合且缺少毛孔、痣和肤色细节。HiFiAlbedo 先从大规模高分辨率 RGB faces 学习“高质量人脸纹理长什么样”，再利用同一个人的 albedo 在不同场景中应保持不变这一约束，把 texture prior 迁移到 albedo domain。

具体实现分两阶段：

  1. Texture codebook / UV reconstruction：VQGAN 的 quantizer Q\mathcal QQ、texture codebook CT\mathcal C^TCT 和 decoder G\mathcal GG 先在大规模人脸上训练并冻结；image encoder Euv\mathcal E_{uv}Euv​ 将单图编码到该 codebook。DlatentD_{latent}Dlatent​ 对齐有限真实 UV 的 latent 分布，DimageD_{image}Dimage​ 对齐随机视角渲染与真实脸分布。
  2. Texture-to-albedo adaptation：对同身份、不同光照的多张图先做 attribute filtering；冻结 Euv\mathcal E_{uv}Euv​ 提取并拼接特征，Pk/PvP_k/P_vPk​/Pv​ 生成 key/value，learnable query latent 经 cross-attention 提取跨图共享成分。
  3. 共享 latent reshape 后经 Q\mathcal QQ 与 G\mathcal GG 解码为 albedo；贴回 3D face 渲染，以 LPIPS 与 group identity loss 约束重建结果仍对应各输入身份。

实现本质：它把 VQ codebook 的高频生成能力 与 同身份多图的不变性监督 结合。单图可推理，多图会更好地排除特定光照。

8. UVAPM (2025)：低维参数保证稳定，高频 VAE 恢复个性细节

论文：UVAPM: A UV Albedo Parametric Model for High-Quality Face Albedo Generation

图 8a：论文 Figure 2。UVAPM 用 RGB 三组 basis 和系数 α\alphaα 产生 coarse albedo；detail model 用 δ\deltaδ 产生 value-channel 高频残差；几何、光照和材质参数经可微渲染共同拟合输入。

图 8b：论文 Figure 5。左侧 coarse generator 预测低频 value，二者相减得到高频 residual；右侧 VAE 学习该 detail distribution。

简介：UVAPM 试图保留传统 3DMM “参数少、可解释、易优化”的优势，同时解决线性纹理基底过平滑的问题。低频肤色和大结构由 UV albedo parametric basis 控制，高频胡须、眉毛、眼窝和皮肤纹理由 detail latent 补充。

具体数据流：

  1. UVAPM 为 RGB 通道学习 basis Br,Bg,BbB_r,B_g,B_bBr​,Bg​,Bb​；albedo coefficient α\alphaα 线性组合得到 coarse RGB，再转 HSV。
  2. UV detail model 由 coefficient δ\deltaδ 产生 value-channel residual；它与 coarse VVV 相加，再和原有 H/SH/SH/S 合成为最终 RGB albedo TRGBT_{RGB}TRGB​。
  3. HIFI3D++ 用 identity/expression coefficients (β,ξ)(\beta,\xi)(β,ξ) 产生 shape，SH coefficient γ\gammaγ 产生 illumination；pose θ\thetaθ、几何、albedo 与光照共同进入 differentiable renderer。
  4. 对输入图优化 (α,δ,β,ξ,θ,γ)(\alpha,\delta,\beta,\xi,\theta,\gamma)(α,δ,β,ξ,θ,γ)，以渲染重建损失反向更新参数。
  5. detail VAE 的训练目标来自真实 albedo 的 VVV 通道减去 coarse generator 预测值，迫使 latent 只承载高频 residual，而不是重新学习肤色和低频结构。

实现本质：这是 显式低维参数模型 + learned residual VAE + analysis-by-synthesis optimization，控制性强，但低维 basis 会限制训练集之外的罕见外观。

9. OpenDelight (SIGGRAPH 2026)：用 source-aware token 融合两种去光照数据

论文：OpenDelight: Learning a Delighting Prior for Facial Appearance Capture in the Wild

图 9：论文 Figure 4。OLAT 与 rendered-scan 样本分别附加不同 source-aware tokens；ViT 处理图像与数据源 token，decoder 只接收图像 token。

简介：FaceOLAT 接近真实照片分布，但 uniform-light albedo 较模糊并可能烘焙镜面；渲染 Light-Stage scans 的 albedo 锐利且物理正确，却与真实照片存在 domain gap。OpenDelight 用 Dataset Latent Modulation（DLM）让小容量 source token 吸收数据集风格，让大容量 backbone 专注学习共享的 delighting mechanism。

具体实现：

  1. 皮肤区域输入被切成 patch tokens，并附加对应数据源的 4 个 source-aware tokens diod_i^odio​ 或 dird_i^rdir​。
  2. MAE 初始化的 ViT-Base encoder 对图像和 source token 做 self-attention；编码后丢弃 source token，只将图像 token unpatchify 并送入轻量 convolutional decoder。
  3. 基础预测 A^=Fbase(I,d∗)\hat A=F_{base}(I,d^*)A^=Fbase​(I,d∗) 使用 L1 + LPIPS 监督；推理野外图像时显式选择 rendered-scan token，将输出导向更锐利、物理更正确的 albedo style。
  4. 因 ViT 没有 skip connection，另训练 UNet Fdetail(I,A^)F_{detail}(I,\hat A)Fdetail​(I,A^) 恢复毛孔等高频细节。基础网络工作在 512×512，detail network 工作在 768×768。
  5. 完整 capture pipeline：野外视频 → COLMAP/2DGS/Wrap3D 几何 → 16 个视角分别 delight → 融合成 1K UV → 优化全局 SH illumination → 反射率超分到 4K。

实现本质：它不是单图 complete-UV diffusion，而是 delighting prior + multi-view UV fusion + simplified inverse rendering，目标是可重光照采集而非单张好看的 baked texture。

10. MARCUS Avatar / MARC (2026)：从 UV 补全一路做到 4K PBR maps

论文：MARCUS Avatar；项目页

图 10a：论文整体 pipeline。单图先恢复几何并反投影 incomplete UV，之后依次执行 texture inpainting、light homogenization、material estimation 与 4K super-resolution。

图 10b：论文训练架构。左侧是 albedo、normal、roughness/specular/displacement 三个联合 diffusion 分支和可微 GGX shader；右侧是 inpainting / homogenization 的单任务 LoRA。

简介：这篇论文把人脸纹理问题定义成完整资产生产链，而非只生成一张 RGB UV。它先解决不可见区域，再移除烘焙光照，最后联合预测相互耦合的 intrinsic/PBR maps，从而支持新 HDRI 下的材质重光照。

推理框架：

  1. 单图 geometry frontend 融合 ConvNeXt-V2 局部特征与冻结 DINOv3 语义特征，回归人脸几何和相机；将可见像素反投影到 UV 得到 incomplete texture。
  2. Inpainting LoRA 补全侧脸、额头和遮挡区；Light-Homogenization LoRA 消除局部阴影、高光和曝光差，使纹理接近 intrinsic albedo。
  3. Material estimation 联合输出 albedo、normal、roughness、specular 与 displacement；最后用超分模块将 1K maps 提升到 4K。

训练框架：

  1. 冻结 Qwen2.5-VL / multimodal diffusion transformer 与 VAE 主干，只训练 task-specific LoRA，降低少量 PBR scans 训练时的先验破坏。
  2. 材质阶段将 TalbT_{alb}Talb​、TnrmT_{nrm}Tnrm​、Trough/spec/dispT_{rough/spec/disp}Trough/spec/disp​ 编码成三个 batch 分支；每个分支有独立 LoRA。
  3. 在 DiT block 内执行 Batch-Dimension Cross-Intrinsic Attention，使同一 texel 的颜色、法线和反射属性互相解释，减少跨图不一致。
  4. 解码后的 PBR maps 与几何 position/normal/tangent 一起进入 microfacet GGX shader；可微 BRDF rendering loss 检查这些材质图在新光照下是否共同产生正确外观。
  5. Inpainting 与 homogenization 各用单任务 LoRA；homogenization 的训练通过环境光照/阴影合成数据构造输入与目标对。

实现本质：这是 级联 UV diffusion + 多分支 intrinsic diffusion + differentiable BRDF supervision。它输出最完整，但也最容易发生前级几何/补全错误向后级材质分解传播。

架构路线的核心差异

关键问题 代表方法 解决方式
如何把真实可见像素放到正确 UV 位置 Yin、FFHQ-UV、UV-IDM、FaceRefiner learned sampler、3D unwrap/remap 或 differentiable render
没有完整 paired UV GT 如何训练 Yin、FreeUV pseudo-GT 或 appearance/structure 分域训练
如何防止生成纹理“换脸” UV-IDM、FaceRefiner、HiFiAlbedo partial-UV cross-attention、输入视角渲染反馈、group identity constraint
如何摆脱脆弱的 3D fitting OMGTex image-to-UV paired learning + gradient-guided alignment
如何从 baked RGB 走向可重光照 albedo HiFiAlbedo、UVAPM、OpenDelight codebook domain adaptation、显式参数分解、delighting prior
如何形成引擎可用 PBR asset MARCUS Avatar homogenization + joint intrinsic maps + differentiable GGX loss
